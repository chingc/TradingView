# TradingView

Indicators for [TradingView](https://www.tradingview.com/).

## history.pine

- Track change over any number of trading sessions.
- Highlight bars that rise above a certain value.
- Highlight bars that fall below a certain value.
- Track the occurrence of highlighted bars.

[View on TradingView](https://www.tradingview.com/script/IaoDKoZe-Price-Change-History/)

## ribbon.pine

- Draws a ribbon of moving averages.

[View on TradingView](https://www.tradingview.com/script/BYlBVO8b-MA-Ribbon/)
